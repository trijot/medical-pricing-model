# Regulator / Stakeholder Questions (Living Doc)

Use this to capture questions and responses during filing / approvals.

## Common questions
1. **Why did rates change?**
   - Point to `CHANGELOG.md`, PR discussion, and output exports.

2. **What assumptions changed vs last year?**
   - Point to `ASSUMPTIONS.md` (with dates) and the PR commit history.

3. **What are the largest increases/decreases?**
   - Point to `outputs/dislocation_analysis.csv` and the summary in the PR.

4. **How did you validate the model?**
   - Point to `model/Validation_Checks.xlsx` and peer review checklist.
